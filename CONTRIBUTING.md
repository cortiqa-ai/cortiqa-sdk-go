# Contributing to Cortiqa Go SDK

We appreciate contributions to the Cortiqa Go SDK!

## Development

```bash
git clone https://github.com/cortiqa-ai/cortiqa-sdk-go.git
cd cortiqa-sdk-go

# Run tests
go test -v ./...
```

## Guidelines

- Use standard library wherever possible. Avoid adding third-party runtime dependencies.
- Follow standard Go formatting (`go fmt`).
- Ensure all public types and functions have clear godoc comments.
