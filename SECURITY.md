# Security Policy

Cortiqa takes security very seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability:
1. Please do not disclose it publicly in GitHub issues or discussions.
2. Email **security@cortiqa.co** or **team@cortiqa.co**.
3. We will acknowledge receipt within 48 hours and work with you on a patch release.
